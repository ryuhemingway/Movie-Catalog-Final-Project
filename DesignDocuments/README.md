# Design Documents

You may have multiple design documents for this project. Place them all in this folder. File naming is up to you, but it should be clear what the document is about. At the bare minimum, you will want a pre/post UML diagram for the project. 

## Contents

This folder contains the design documentation for the CineVaultApplication.


- **DesignDocument.md** - The main design document, including our UML diagrams and overall
  architecture decisions for the CineVaultApplication project.

- **CineVaultGUIWireframe.md** - The wireframes and design iterations for the GUI, it shows how
  the layout evolved from our initial sketches to the final implementation.

- **GuiTestingHistory.md** - A record of manual GUI testing performed throughout the project
    and implementation of View classes and components.

- **screenshots/** - Screenshots referenced by the documents above, including wireframe designs
  and the final completed application.
